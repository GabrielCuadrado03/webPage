# Módulo de Autenticación (Auth)

Aquí se gestionarán todas las vistas y componentes del flujo de acceso de **Ethereal Vapes**:
- Pantalla de inicio de sesión (Login).
- Pantalla de registro de nuevos usuarios (Register).
- Pantalla de recuperación de contraseña (Forgot Password).
- Componentes visuales y validaciones de formularios responsivas.
