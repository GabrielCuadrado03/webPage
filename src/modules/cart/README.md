# Módulo de Carrito (Cart)

Aquí se gestionarán todas las vistas y componentes del carrito de compras y pasarela/checkout de **Ethereal Vapes**:
- Resumen del carrito.
- Edición de cantidades en carrito.
- Formulario de checkout y facturación.
- Integración con Firebase para guardar la orden/pedido.
