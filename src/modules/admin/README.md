# Módulo de Administración (Admin)

Aquí se gestionarán todas las vistas y componentes del panel administrativo de **Ethereal Vapes**:
- Gestión de productos (crear, editar, eliminar en Firestore).
- Gestión de combos.
- Visualización de órdenes de compra recibidas.
- Métricas o analíticas rápidas de ventas.
