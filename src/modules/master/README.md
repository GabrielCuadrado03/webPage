# Módulo Master Admin (Parametrización Global y Theming)

Este módulo confidencial permite al propietario del sitio gestionar de manera centralizada:
- **Theming & Colores**: Modificación en caliente de la paleta mediante CSS Variables y Tailwind v4.
- **Barra de Anuncios**: Notificaciones de ofertas, códigos de descuento y envíos gratis.
- **Identidad de Marca**: Nombre, eslogan y badges.
- **Textos & Copys**: Hero banner, catálogo y combos promocionales.
- **Canales de Contacto**: Teléfono de WhatsApp y plantilla dinámica de pedido.
- **Cuentas Bancarias**: Instrucciones y datos para transferencias.
- **Disaster Recovery**: Copias de seguridad en JSON y restauración en 1 clic.

### Seguridad:
- Ruta oculta protegida mediante `Master Passkey`.
- Acceso camuflado para usuarios no autorizados.
